# snake-game
The Snake Game is a game where a snake grows longer each time it eats food and the game ends if it runs into a wall or itself. Along with the basic setup, such as the grid, snake, game loop, movement, keyboard controls, and features like food spawning, collision detection, scoring, and restart prompts, I added several extra features to enhance the experience. These additions include a high score tracker, a starter screen, and a sound effect that plays when the snake eats food. I also made it so the snake gradually moves faster as it grows, increasing the difficulty over time. In addition, players can unlock the ability to change the snake’s color once they reach a score of at least 20.
